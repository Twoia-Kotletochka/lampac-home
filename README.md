# Lampac Home

Готовый к запуску **self-hosted backend Lampac NextGen** для медиаплеера **Lampa** — в одном
Docker-контейнере. Разворачивается одной командой и сразу даёт:

- 🎬 **онлайн-источники** — 70+ балансеров фильмов и сериалов;
- 🧲 **торренты** — встроенный **TorrServer** + торрент-парсер (**JacRed**, Jackett-совместимый API),
  настраивается сам, вручную ничего вводить не нужно;
- 📺 **DLNA**, синхронизация профилей, закладок и таймкодов между устройствами;
- 🔓 возврат разделов «Торренты» и «Парсер» в магазинных сборках Lampa, где они скрыты демо-режимом;
- 🖼 **постеры и TMDB через ваш сервер** — клиент не ходит на image.tmdb.org напрямую;
- 🇺🇦 **украинский IPTV** — свой плагин с сотнями каналов и ежедневным обновлением плейлиста;
- 🔌 **подборка проверенных плагинов** — логотипы, Interface Mod, кнопка выхода, Torrent Download,
  дорожки торрента, доп. категории, «Новинки», подборки стримингов, Anime Skip;
- ▶️ **запуск во внешнем плеере** — клик по торренту открывает его в VLC на компьютере, без ввода пароля;
- 🌍 **вход снаружи по домену** — Cloudflare-туннель с логином и паролем, при этом
  локальная сеть продолжает работать без пароля (см. ниже).

## Быстрый старт

```bash
git clone https://github.com/Twoia-Kotletochka/lampac-home.git
cd lampac-home
./install.sh
```

`install.sh` подтянет Docker-образ из реестра ghcr.io, сгенерирует пароль,
создаст каталоги данных и запустит контейнер.

> Для установки **без интернета** есть отдельный самодостаточный архив с уже
> вложенным Docker-образом (в репозитории его нет — он большой). Если такой архив
> у вас есть, распакуйте его и запустите тот же `./install.sh` — он найдёт образ рядом
> и загрузит из файла, а не из реестра.

После установки скрипт покажет адрес. Обычно это:

| Что | Адрес |
|-----|-------|
| Веб-Lampa | `http://SERVER_IP:9118` |
| Плагин для Lampa на ТВ | Настройки → Расширения → `http://SERVER_IP:9118/on.js` |
| Парсер торрентов | Jackett — настраивается автоматически |
| TorrServer | `http://SERVER_IP:9118/ts` |

На телевизоре вводится **только один** адрес — `…/on.js`. Всё остальное (источники, TorrServer,
парсер, IPTV, разблокировка) приезжает автоматически.

> Адрес сервера **нигде не зашит**: Lampac подставляет его сам через переменную `{localhost}`
> по тому адресу, по которому к нему обращается клиент. Поэтому конфиг работает на любом IP/домене
> без правок — просто используйте свой адрес там, где добавляете плагин `on.js`.

## Вход снаружи по домену (необязательно)

Каталог `edge/` поднимает доступ к вашей Lampa из интернета через **Cloudflare-туннель**,
закрытый логином и паролем. Порты на роутере открывать не нужно.

```bash
cd edge
./setup.sh
```

Скрипт спросит логин и пароль (или сгенерирует надёжный), посчитает bcrypt-хеш,
соберёт конфиг и запустит туннель. Токен туннеля берётся в Cloudflare:
**Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared**, Public hostname с
типом `HTTP` и адресом `127.0.0.1:9119`.

Как это устроено:

```
интернет → Cloudflare → cloudflared → прокси :9119 (логин/пароль) → lampac :9118
локальная сеть ────────────────── напрямую ──────────────────────→ lampac :9118
```

- порт `9119` слушает **только loopback** — из локальной сети его не видно,
  войти по паролю можно исключительно через туннель;
- **локальные клиенты пароль не спрашивают** — телевизор ходит на `:9118` как раньше;
- **админские пути наружу закрыты совсем**, даже с верным паролем: веб-админка TorrServer,
  его настройки и выключение, загрузка произвольных `.torrent`, а также удаление файлов
  и управление закачками в DLNA. Просмотр при этом работает полностью;
- токен туннеля хранится в `.env`, а не в командной строке — иначе его видно
  через `docker inspect` и в списке процессов.

> ⚠️ Раздел **Private Networks** в Cloudflare не включайте: он пробрасывает в туннель
> целую подсеть и открывает всю вашу домашнюю сеть. Нужен только Public Hostname.

> ⚠️ Просмотр видео через бесплатный тариф Cloudflare формально ограничен их условиями
> (непропорциональный объём не-HTML трафика). Учитывайте это.


### Запуск во внешнем плеере одним кликом

Клик по файлу торрента может сразу открывать его в плеере на компьютере (VLC и т.п.),
а не во встроенном плеере браузера. Пароль плеер при этом не спрашивает.

Как устроено: клик отдаёт маленький `.m3u`, который собирает сам сервер (`/openin`) и
дописывает в него **токен потока**. Токен открывает только `/ts/stream` — ни интерфейса,
ни API, ни настроек по нему не получить, и он не заменяет пароль входа. Токен генерирует
`setup.sh` в `streamkey.txt`; в репозитории его нет.

Встроенный плеер не сломан: Lampa штатно умеет отменять запуск через `abort()` в событии
`create`, так что переключение честное, без подмены функций. Отключается в
**Настройки → Плеер → «Открывать торренты во внешнем плеере»**.

Чтобы браузер не переспрашивал про скачанный файл, отметьте у него
«Всегда открывать файлы этого типа» — после этого клик действительно один.

## Требования

- Docker + docker compose (плагин v2)
- Linux-хост (проверено на Debian). `network_mode: host` — нужен для DLNA/TorrServer.
- ~3 ГБ под образ; место под кэш и торренты — папки `cache/` и `data/`.

## Что внутри

```
docker-compose.yaml          переносимый (все пути относительные)
install.sh                   установка одной командой
lampac-image.tar(.gz)        Docker-образ (только в самодостаточном архиве; в git его нет)
lampac-docker/
  config/init.conf           конфиг Lampac (модули, плагины, парсер) — без IP, через {localhost}
  config/passwd.example      пример; реальный passwd создаёт install.sh и он в .gitignore
  plugins/unlock.js          снятие демо-режима (возврат торрентов/парсера в магазинных сборках)
  plugins/uatv.js            плагин украинского IPTV (каналы встроены)
  plugins/lampainit.js       настройка парсера при каждом запуске
  plugins/on.js              единая точка входа для ТВ: разблокировка, парсер, IPTV, чистка мусора
  gen_uatv.py                генератор uatv.js из m3u-плейлистов
  refresh_uatv.sh            ежедневное обновление IPTV (ставится в cron)
edge/                        внешний доступ (необязательно)
  setup.sh                   настройка входа по логину/паролю + туннель
  Caddyfile.template         конфиг прокси: авторизация и закрытие админских путей
  docker-compose.yaml        прокси + cloudflared
  static/ts.js               свой ts.js: чинит конфликт авторизаций + запуск во внешнем плеере
  .env.example               куда вписать токен туннеля
cache/, data/                кэш и данные TorrServer/DLNA (создаются при установке)
```

## Обслуживание

- Обновить образ: `docker compose pull && docker compose up -d`
- Логи: `docker logs lampac`
- Обновить IPTV вручную: `./lampac-docker/refresh_uatv.sh`
- Сменить пароль внешнего входа: вписать новый в `edge/creds.txt`, удалить `edge/hash.txt`,
  запустить `edge/setup.sh` заново

## Грабли, на которые мы наступили

Пригодится, если будете переделывать под себя.

- **Lampac за обратным прокси** читает не `X-Forwarded-*`, а собственные заголовки
  `xscheme` и `xhost` — по ним он строит адреса плагинов. Без них по домену приедут
  `http://127.0.0.1:9118/...` и страница сломается на mixed content.
- **Две Basic-авторизации конфликтуют.** Штатный `ts.js` включает на клиенте
  `torrserver_auth`, и Lampa начинает слать на `/ts/*` свой заголовок `Authorization`
  для TorrServer. Он затирает пароль входа, прокси отвечает `401`, и браузер
  бесконечно переспрашивает пароль. Клиенту эта авторизация не нужна — Lampac
  подставляет данные TorrServer сам, поэтому для внешнего входа `ts.js` подменяется.
- **`/ts/shutdown` реально гасит TorrServer.** В Lampac защита от него не работает:
  сравнивают `path.StartsWith("/shutdown")`, а `path` равен `"/ts/shutdown"` —
  условие всегда ложно. В локальной сети этот путь доступен без пароля.
- **Нельзя монтировать весь `/lampac/data`** — в образе там базы источников и утилиты,
  пустой маунт роняет приложение. Монтируйте только подкаталоги `data/ts` и `data/dlna`.
- **Плагины с проверкой origin.** Некоторые сторонние плагины на «чужих» сборках
  показывают «Ошибка доступа» при старте. Перед добавлением стоит проверять.
